# Задача: перевести всё приложение Posta на дизайн «Студии»

Ты работаешь в проекте `/var/www/html/posta` (Posta, ветка `go-rewrite`; сервер на Go, интерфейс — обычные HTML/CSS/JS-модули без сборки). Владелец решил: дизайн страницы `studio.html` («Студия») становится дизайном **всего** приложения. Сейчас приложение (`index.html` + `css/app.css` + `js/*.js`) выглядит по-старому: светлая тема «День» и тёмная «Эфир» в стиле телемагазина (жёлтые плашки, толстые чёрные рамки, жёсткие тени, шрифты Oswald/Jost, бегущая строка). Это надо заменить на тёмный стиль студии.

Работа — **только оформление и раскладка**. Логику, запросы к API, тексты и поведение вкладок не менять.

## Решения владельца (не пересматривать)

1. **Одна тёмная тема — студийная.** Темы «День» и «Эфир» убрать целиком:
   - переключатель `.theme-switch`;
   - `js/theme.js` и его вызов `initializeTheme()` в `js/main.js`;
   - скрипт темы в `<head>`;
   - все правила `:root[data-theme=…]`.
   `<meta name="theme-color">` — `#090b14`.
2. **Бегущую строку `.air-ticker` убрать** (разметку и стили). Подпись загрузки — «Загрузка…».
3. **Раскладка приложения — как у студии:**
   - левое меню вместо верхних вкладок;
   - в центре строка-шапка (выбор темы, журнал);
   - ниже контент вкладки.
   Студия и приложение должны выглядеть как один продукт: одинаковые логотип, меню, профиль внизу меню, шапка.
4. **Логотип** — как в студии (`.brand`: ромб-градиент + «Posta» / «ИИ-студия контента»), ссылка на `./` (студию). Жёлтую плашку «postä» убрать.
5. **Шрифт** — только Rubik. Oswald и Jost из интерфейса приложения убрать: `@font-face`, `--font-display`, `--font-tag` → `var(--font-ui)`, `text-transform: uppercase` и разрядку у заголовков и вкладок снять. Сами файлы шрифтов в `fonts/` не удалять: их использует лендинг.
6. `landing/`, `studio-globe.js`, `studio-land.js` и сайт Keep or Skip **не трогать**.

## Как делать

### Шаг 1. Общие стили: `css/shell.css`

Создай `css/shell.css` — общий для студии и приложения:
- `@font-face` Rubik (перенеси из `studio.css`) и Noto Color Emoji (перенеси из `app.css`, строки ~15–26, без изменений: см. лицензию в комментарии);
- токены студии (`:root`, `color-scheme: dark`);
- основа: `body`, `a`, `button/input/select`, `.muted`, `:focus-visible` (обводка `2px solid var(--accent)`);
- **оболочка**: `.studio` (сетка), `.side` и всё внутри (`.brand`, `.side-nav`, `.side-list`, `.profile`, `.avatar`), `.main`, `.top`, `.search`, `.model-pill`, `.panel`, `.box`, `.cta`, `.ghost`, `.chips`, `.bar`, `.steps`, `.action`, `.activity`;
- адаптив оболочки (1200 px, 760 px).

Затем:
- из `css/studio.css` убери перенесённое — останется только своё (смотровое окно, лента, плитки, просмотр поста);
- в `studio.html` подключи `css/shell.css` **перед** `css/studio.css`;
- проверь, что студия выглядит **точно как раньше**: сравни снимки до и после (см. «Проверка»).

### Шаг 2. Оболочка приложения в `index.html`

1. Подключи `css/shell.css` перед `css/app.css`.
2. Оберни страницу в `<div class="studio">` с тремя частями, как в `studio.html`.
3. **Левое меню `.side`:**
   - логотип;
   - первый пункт «Главная» — ссылка `href="./"`;
   - дальше вкладки приложения. Сделай их кнопками `<button class="tab-btn" type="button" role="tab" data-tab="…">` с тем же текстом. Внутри можно добавить значок `<i>` как в студии (✦ Подбор, ▣ Предложка, ▦ Календарь, ⟲ Источники, ❖ Дерево, ◎ Тест ИИ, ⚙ Личный кабинет, ★ Админка). Кнопка «Админка» остаётся с `hidden`: её показывает `js/account.js:36`.
   - внизу профиль `.profile` (ссылка на вкладку кабинета). Имя бери так же, как `loadContent()` в `js/studio.js`; лучше вынеси эту функцию в общий маленький модуль и не копируй.
   - **Стили:** `.side-nav .tab-btn` должна выглядеть как `.side-nav a` в студии (во всю ширину, слева, без рамки), `.tab-btn.active` — как `.is-active`. Старые стили `.tab-btn` в `app.css` (Oswald, рамка, жёлтая заливка, тень) удали.
4. **Шапка `.top`:** слева `#topic-tabs` (выбор темы; меню `.topic-switch-menu` — тёмная панель `var(--panel)` с рамкой `var(--line)` и скруглением 14 px), справа `#console-mini` — в виде `.model-pill`. Кнопка `#debug-toggle` остаётся там же, где сейчас.
5. **Центр `.main`:** все `div.view-panel` и остальное содержимое `main.app-main`. ID и классы самих панелей и всего внутри них не менять.
6. **Правая колонка `.panel`:** в приложении её нет — сетка в две колонки (`grid-template-columns: 250px minmax(0, 1fr)`). Например, класс `studio is-app` и отдельное правило в `shell.css`.
7. **Журнал `.activity-console`** остаётся всплывающей панелью, как сейчас (её положение задаёт `placeConsole()` в `js/core.js`). Оформление — как `.box` студии.
8. `#tab-inactive` и `#debug-banner` — полоса над `.main`, тёмная.
9. Удали из `app.css` старую раскладку: `body { display: grid … }` для ≥ 900 px, `.app-top`, `.app-brand`, `.app-brand-plate`, `.air-ticker*`, `.theme-switch*` и блок «Шапка на широком экране». Ширину панелей (`.view-panel`, `max-width: 420px`, `.wide-panel` 1100 px) оставь, но центрируй внутри `.main`.

Проверь: вкладки переключаются щелчком, `index.html#calendar` открывает календарь, «Главная» ведёт в студию, на ширине 500 px меню — горизонтальная полоса с прокруткой.

## Правила
- **Не переименовывай ID и классы, которые ищет JS.** Перед удалением или переименованием класса проверь:
  ```
  grep -rn "имя-класса" js/ index.html studio.html
  ```
  Если класс используется в JS, оставь его и меняй только стиль.
- Не меняй тексты интерфейса, кроме «Эфир начинается…» → «Загрузка…».
- Не трогай Go-код (`internal/`, `cmd/`), API и базы данных.
- Доступность: контраст текста ≥ 4.5:1 (мелкий серый `--muted` на `--panel` проходит), видимый `:focus-visible`, `prefers-reduced-motion` продолжает отключать анимации.
- Без внешних CDN и шрифтов из интернета.
- Делай коммит после каждого шага (сообщения по-русски, как в истории). Боевой сайт не выкатывай: это сделает владелец командой `sudo sh deploy/install.sh`.

## Проверка

**Dev-сервер** (боевая база не затрагивается; Postgres для разработки слушает порт 55432):
```
cd /var/www/html/posta && go build -o bin/posta ./cmd/posta
POSTA_DEV=1 POSTA_LISTEN=127.0.0.1:8097 POSTA_MEDIA_DIR=/var/lib/posta/media POSTA_MEDIA_URL=media bin/posta serve &
```
Значения `POSTA_PG` и `POSTA_CH` берутся из `posta.env` в корне проекта.

**Вход для headless.** Нужна сессия владельца в dev-базе. Токен — 64 hex-символа, в таблице лежит его sha256:
```
SID=$(head -c 32 /dev/urandom | xxd -p -c 64); H=$(printf %s $SID | sha256sum | cut -d' ' -f1)
LD_LIBRARY_PATH=~/posta-dev/pgroot/usr/lib/x86_64-linux-gnu ~/posta-dev/pgroot/usr/lib/postgresql/18/bin/psql -h 127.0.0.1 -p 55432 -U posta posta \
  -c "insert into sessions values ('$H','901e57ea701ac607bf778a2a175ee6fd',extract(epoch from now())::bigint,extract(epoch from now())::bigint)"
```
Страница: `http://127.0.0.1:8097/dev-login?sid=$SID&to=/index.html%23calendar` (кука `pm_sid`).

**Снимки:**
```
google-chrome --headless=new --no-sandbox --disable-gpu --hide-scrollbars --window-size=1500,1000 --virtual-time-budget=9000 --screenshot=out.png "<адрес>"
```
- Ширины 1500, 1100 и 500 (меньше 500 headless Chrome не умеет).
- Каждая вкладка: `#content`, `#proposals`, `#calendar`, `#sources`, `#account`. Дерево, Тест ИИ и Админку открывай щелчком или временно через `switchTab` в консоли.
- Снимки студии `/` до и после шага 1 должны совпасть.
- `requestAnimationFrame` в headless иногда не срабатывает, анимации на снимках могут застыть. Это не ошибка вёрстки.

**После проверки:**
- останови dev-сервер;
- удали свою сессию из dev-таблицы `sessions`.

**Готово, когда:**
- на всех вкладках нет жёлтого, толстых чёрных рамок, жёстких теней, Oswald/Jost и заглавных заголовков;
- меню слева одинаковое в студии и в приложении;
