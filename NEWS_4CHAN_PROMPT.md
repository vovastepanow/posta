# Задача: новостные сайты (vc.ru и т.п.) и 4chan как источники

Ты работаешь в PHP-проекте `/var/www/html/posta` (Posta: собирает посты из источников по теме пользователя,
модель оценивает, пользователь публикует в свой Telegram-канал). Источники уже есть: Telegram, VK, RSS (в т.ч.
YouTube, Pinterest, Tumblr), Одноклассники, TikTok, Двач. Владелец: «надо ещё парсить новостные сайты — vc.ru
всякие — и 4chan».

## Что проверено с этого сервера (2026-10-23, перепроверять не нужно)

**Новостные сайты — ленты RSS отдаются, наш `rss_fetch_posts` их уже читает:**

| Лента | Постов с картинкой / всего | Длина текста | Пример |
|---|---|---|---|
| `https://vc.ru/rss` | 10 / 12 | ~140 симв. | «The Browser Company закроет браузер Arc» |
| `https://dtf.ru/rss` | 12 / 12 | ~155 | |
| `https://habr.com/ru/rss/articles/` | 30 / 40 | ~425 | |
| `https://rssexport.rbc.ru/rbcnews/news/30/full.rss` | 13 / 30 | ~235 | |
| `https://lenta.ru/rss` | 30 / 200 | **~49** | |
| `https://ria.ru/export/rss2/archive/index.xml` | 30 / 100 | ~71 | |
| `https://tass.ru/rss/v2.xml` | 24 / 100 | ~238 | |
| `https://3dnews.ru/news/rss/` | 30 / 64 | ~849 | |

`kommersant.ru/RSS/news.xml` → 301 (проверь, куда), `pikabu.ru/xmlfeeds.php` → HTML, не лента.

Проблемы: **(1)** у многих записей нет картинки в ленте — `rss_parse` их выкидывает (у РИА, Ленты, ТАСС — больше
половины); **(2)** текст — только анонс в 50–250 символов, для поста в канал мало; **(3)** одна и та же новость
выходит на РИА, ТАСС, Ленте, РБК — будут дубли; **(4)** новость старше суток никому не нужна, а у нас
`CONTENT_MAX_AGE_DAYS` общий; **(5)** в каталоге нет ни одного сайта — автоподбор их не ищет (поисковики с сервера
не работают), пользователь должен знать адрес.

**4chan — открытый JSON API, работает:**
- `https://a.4cdn.org/boards.json` — 77 досок, у каждой флаг `ws_board` (worksafe): 53 безопасных —
  `3 a adv an biz c cgl ck cm co diy fa fit g gd his int jp k lgbt lit m mlp mu n news o out p po pw qst sci sp tg
  toy trv tv v vg vip vm vmg vp vr vrpg vst vt w wsg wsr x xs`. Небезопасные (`b`, `pol`, `gif`, `s`, `hc`… —
  `ws_board = 0`) — 18+ и/или токсичные.
- `https://a.4cdn.org/<доска>/catalog.json` — треды страницами (`no`, `sub`, `com`, `tim`, `ext`, `replies`,
  `images`, `last_modified`); `https://a.4cdn.org/<доска>/thread/<no>.json` — посты треда.
- Файлы: `https://i.4cdn.org/<доска>/<tim><ext>` (jpg, png, gif, webm, mp4), превью `<tim>s.jpg`.
  **Без заголовков браузера полный файл отдаёт 429**; с `User-Agent` обычного Chrome и
  `Referer: https://boards.4chan.org/<доска>/` и паузой 2–3 с между файлами — 200 (gif 2 МБ, mp4 1–4 МБ).
- Правила API 4chan: не чаще 1 запроса в секунду, `If-Modified-Since` для каталогов и тредов.
- Тексты — на английском; HTML в `com` (`<br>`, `<span class="quote">`, ссылки `>>123`).

**Устройство 4chan повторяет Двач** (доски → треды → посты с файлами). У нас Двач: `lib/sources.php`
(`fetch_2ch_json`, `dvach_thread_posts`, `dvach_post_media`, `dvach_post_text`, `dvach_thread_state`,
`dvach_thread_dead_reason`, `dvach_thread_engagement`, `DVACH_BOARD_TAGS`), `lib/parser.php` (`parse_dvach`,
`dvach_boards_this_run`), `lib/discovery.php` (`dvach_boards_by_tags`, `choose_dvach_boards`,
`dvach_boards_for_topic`), `handlers/sources.php` (`dvach_source_candidates`, `dvach_blocked_boards`).

## Общие правила

- **Не делай git commit.** Перед записью в базу: `cp data/posta.sqlite data/posta.sqlite.bak-news`.
- **НЕ открывай сайт Posta** (`http://localhost/...`): каждая загрузка без куки создаёт пользователя и запускает
  парсер, который нельзя остановить без sudo. Сторонние сайты — можно (через `fetch_public` / `rss_get`).
- **Модели:** новых вызовов моделей в проверках — не больше 10 на часть; оценка постов — существующим конвейером.
- **Каталог общий для всех пользователей.** Тестовые темы — с префиксом `тест-`, после проверки убери их записи.
- **Авторское право:** с новостного сайта в пост идут заголовок, короткая выжимка своими словами (до 2–3
  предложений) и **обязательная ссылка на источник**. Полный текст статьи не публикуем и в карточку не копируем.
  С 4chan — картинки/видео и подпись; источник — ссылка на тред.
- Сетевые запросы к сайтам — только `fetch_public` / `rss_get`, с таймаутами и лимитом размера. Не чаще 1 запроса в
  секунду к одному хосту (общий помощник `host_throttle($host)` через `kv` или файл-замок).
- Код в стиле проекта: короткие функции, комментарии по-русски одной строкой, `RuntimeException` с понятным текстом.

## Часть A. Новость = заголовок + выжимка + картинка + ссылка

1. **Дообогащение записи со страницы статьи** — `article_enrich(array $post): array` в новом `lib/article.php`:
   если у записи RSS нет картинки или текст короче 200 символов — загрузи страницу записи (`url`, только https,
   до 2 МБ, таймаут 10 с, `host_throttle`), возьми `og:image` / `twitter:image` (картинка), `og:description`
   (описание), `article:published_time`, и **основной текст** простым способом: `<article>` или крупнейший блок из
   подряд идущих `<p>` (без скриптов, меню, подписей «Читайте также»). Основной текст хранится в записи как
   `article_text` (до 4000 символов) — только для выжимки и для показа в редакторе, **не** для публикации целиком.
   Кэш результата по `url` в `kv` на 3 дня. Не вышло — запись остаётся как была.
2. `rss_parse`: запись без картинки **не выбрасывается сразу**, а помечается `needs_enrich`; `collect_catalog_source`
   дообогащает до `RSS_ENRICH_PER_FEED = 10` таких записей за проход (самые свежие), остальные без картинки
   отбрасываются как сейчас.
3. **Подпись поста для новости:** в карточке и в редакторе — заголовок жирным, выжимка 1–3 предложения и строка
   «Источник: vc.ru» со ссылкой. Выжимку делает существующая генерация подписи (`channel_caption_generate` или её
   основа) **по запросу пользователя** («Сделать выжимку» в редакторе) — не автоматически для каждого кандидата
   (модель на компьютере владельца). По умолчанию в редактор подставляется `заголовок + анонс + Источник`.
   Ссылку на источник нельзя случайно стереть: при публикации без неё — предупреждение «Добавить ссылку на
   источник?» (Да по умолчанию).
4. **Свежесть:** у записи каталога может быть `max_age_hours`; для новостных сайтов (часть B) — 48. В отбор не
   попадает запись старше. Константа по умолчанию — как сейчас.
5. **Дубли одной новости с разных сайтов:** `news_story_key($title)` — нормализованный заголовок (нижний регистр,
   без знаков, стоп-слов и чисел, первые 6 значимых слов по алфавиту) + Жаккар по словам ≥ 0.6 с недавними (48 ч)
   ключами пользователя. Дубль — «уже известен», остаётся первая (у которой есть картинка). Учти в
   `candidate_is_known` или рядом, только для записей новостных сайтов.

**Проверка:** `php -r` — для 2 записей Ленты и 2 РИА без картинки в ленте `article_enrich` даёт картинку и текст
(покажи длину `article_text` и начало); `rss_fetch_posts` по Ленте даёт теперь больше записей с картинкой (было
30 из 200); две похожие новости (сконструируй) — одна отсеивается как дубль, разные — нет.

## Часть B. Каталог новостных сайтов по темам

1. `lib/news_sites.php`: константа `NEWS_SITES` — проверенные ленты с темами дерева (`TOPIC_TREE`, частные темы по
   ключам) и `max_age_hours`. Начни с проверенных выше (vc.ru → бизнес/технологии/маркетинг; dtf.ru → игры;
   habr → технологии/программирование/нейросети; РБК, РИА, ТАСС, Лента → новости, экономика; 3DNews → гаджеты;
   sports.ru → спорт) и **найди сам** ещё по 2–4 ленты на темы: криптовалюта, инвестиции, недвижимость,
   строительство и ремонт, авто, наука и космос, кино и сериалы, еда, путешествия, здоровье. Ищи на самих сайтах
   (`<link rel="alternate" type="application/rss+xml">`, `rss_discover`), проверяй каждую: 200, ≥ 10 записей,
   последняя запись не старше 2 суток, хотя бы у половины картинка (после `article_enrich` — у большинства).
   **Не бери** ленты, которые отвечают капчей/403, и сайты 18+. У разделов крупных сайтов (РБК, vc.ru) ищи ленты
   разделов — они точнее по теме. В отчёт — таблица всех проверенных лент с результатом.
2. Засев: команда `php tools/cli.php seed-news-sites` — добавляет ленты в каталог `rss_feeds` с их темами
   (повторный запуск ничего не дублирует, существующим записям только добавляет темы). Пометка записи
   `news => true` (для `max_age_hours`, дублей и метки в интерфейсе).
3. **Подбор по теме видит сайты**: тема пользователя, совпадающая с темой сайта или её родителем

   («Новости и политика») берёт ленты своих частных тем.
4. На вкладке «Источники» метка площадки для таких записей — «Сайт · vc.ru» (не «RSS»). Если в выпадающем списке
   есть «RSS и сайты» — переименуй в «Сайты и блоги».

**Проверка:** засев на копии базы (`data/posta.sqlite.bak-news` не трогай, делай засев в рабочую базу после
бэкапа), `collect_posts_by_platform(load_source_db(), "Новости и политика")` и для `тест-крипта` (родитель —
«Криптовалюта») возвращают записи из сайтов; повторный засев — 0 новых.
