# Задача: переключатель «Только быстрая модель» в админке

Ты работаешь в PHP-проекте `/var/www/html/posta` (Posta). Владелец хочет в **админке** включать режим «только быстрая модель»:
все задачи локальной модели (Ollama) идут на маленькую быструю модель вместо основной `qwen3.5-vision` 9B. Режим общий для сервера
(видеокарта одна), включает и выключает только владелец.

## Как сейчас (прочитано 2026-10-24)

- `config.php`: `VISION_MODEL`, `ANALYSIS_MODEL = VISION_MODEL` (полный анализ), `SMART_MODEL = VISION_MODEL` (задачи «раз на тему»: профиль темы, классификация,
  названия каналов, подписи, радар лидов), `PRESCREEN_MODELS = ['qwen3-vl:2b-instruct', 'qwen3-vl:2b', 'qwen2.5vl:3b']` (быстрая оценка: первая установленная).
- `lib/ai.php`: `prescreen_model()` — быстрая модель; `analysis_model()` — основная, а после серии таймаутов на `MAIN_MODEL_SLOW_HOURS` переходит на быструю
  (флаг-файл `MAIN_MODEL_SLOW_FLAG`). Это готовый образец того же переключения, только автоматического.
- `SMART_MODEL` используется **константой** напрямую во многих местах: `lib/topics.php` (439, 612, 802), `lib/channel_style.php` (65, 115), `lib/discovery.php` (129, 496),
  `lib/fourchan.php` (106), `lib/ai.php` (427, 488, 719), `lib/news.php` (108), `lib/ollama_classifier.php` (`LEAD_MODEL = SMART_MODEL`).
  `ANALYSIS_MODEL` напрямую — `lib/ai.php`, `handlers/account.php` (777–778 — панель моделей, 842 — выгрузка).
- Админка: `index.html` — `#admin-tab`, навигация `data-admin-nav` (Радар, Базы данных, Куки и данные), секции `data-admin-section`; переключение — `js/account.js` (~27–36).
  Доступ только владельцу: `radar_is_owner()` (`lib/radar_admin.php`, kv `admin:owners`); API админки — `handlers/radar.php`: `?op=` → `admin_api_<op>()`, вне владельца — 404.

## Что сделать

1. **Флаг**: `kv admin:fast_only` (bool). Функции в `lib/ai.php`: `fast_only_mode(): bool` (кэш в `static` на время процесса не делай — парсер живёт долго,
   читай из kv не чаще раза в 30 с) и `fast_only_set(bool $on)`.
2. **Модели через функции**:
   - `analysis_model()` — при `fast_only_mode()` возвращает `prescreen_model()`;
   - новая `smart_model()` — `fast_only_mode() ? prescreen_model() : SMART_MODEL`; замени **все** прямые использования `SMART_MODEL` в вызовах модели на `smart_model()`
     (`LEAD_MODEL` — тоже через функцию). Константу `SMART_MODEL` оставь в `config.php`.
   - Места, где сравнивают `$model === SMART_MODEL` / перебирают `[SMART_MODEL, prescreen_model()]` (`lib/topics.php` 439–456, 612; `lib/discovery.php` 496) — чтобы при
     совпадении моделей не было двойного запроса (`array_unique` уже есть в одном месте — сделай так же везде) и чтобы пометка `'smart'` была честной (`false` в быстром режиме).
   - Если быстрая модель не установлена (`prescreen_model()` вернула основную) — режим ничего не меняет; в админке это видно (п. 4).
3. **При включении** выгрузить основную модель из видеопамяти (`ollama_unload_model(ANALYSIS_MODEL)`, как в `main_model_note_failure`), чтобы быстрая целиком поместилась в VRAM.
4. **API**: в `lib/radar_admin.php` — `admin_api_models($in)` → `{fast_only, fast_model, main_model, fast_installed}` и `admin_api_models_save($in)` (`{fast_only: bool}`).
5. **Интерфейс**: новый раздел админки «Модели» (кнопка в `.account-nav` админки и секция `data-admin-section="models"`), в стиле соседних карточек (`account-card`, `check-chip`):
   - галочка «Только быстрая модель (<имя>) — для всех задач: быстрее, но хуже отбор»;
   - строка состояния: какая модель сейчас у анализа и у «умных» задач;
   - если быстрой модели нет — галочка выключена, подсказка, какую поставить (`ollama pull qwen3-vl:2b-instruct`).
   JS — отдельный небольшой модуль или в `js/radar.js` рядом с остальной админкой, как удобнее по коду.
6. **Журнал парсера**: строка «Модели: быстрая оценка — …, полный анализ — …» в `run_collector` (`lib/parser.php`) уже есть — добавь к ней « (режим «только быстрая модель»)», когда он включён.

## Ограничения

- По умолчанию режим **выключен**; ничего не меняется, пока владелец не включит.
- **Не открывай приложение в headless-браузере с чистым профилем** — новая загрузка = новый пользователь + парсер.
- Стиль кода как в соседних файлах. Не коммить.
