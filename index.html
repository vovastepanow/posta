    Telegram

    Публикация постов в ваш Telegram-канал прямо из приложения. Для этого нужен бот: он отправляет посты в канал. Токен бота хранится на сервере в зашифрованном виде.

    1. Создайте бота. Откройте @BotFather в Telegram, отправьте ему /newbot, придумайте имя и ник (ник должен заканчиваться на bot). В ответ BotFather пришлёт токен — длинную строку вида 123456789:AA…. Скопируйте её. Подробнее: инструкция Telegram.
    2. Добавьте бота в канал. Откройте свой канал → название канала вверху → «Управление каналом» (значок карандаша) → «Администраторы» → «Добавить администратора» → найдите своего бота по нику. В правах оставьте включённым «Публикация сообщений». Бот должен быть именно администратором, иначе он не сможет писать в канал. Если канала ещё нет: как создать канал.
    3. Подключите здесь. Вставьте токен и адрес канала: @имя_канала или ссылку t.me/имя_канала. У закрытого канала без имени укажите числовой id вида -1001234567890 (его покажет @getidsbot, если переслать ему любой пост из канала). Приложение проверит бота и права и подключит канал.

    Отложенные посты средствами Telegram

    Нужны, чтобы публиковать по расписанию. У бота нет отложенной отправки, а у вашего аккаунта есть: пост встанет в «Отложенные» канала и выйдет сам в назначенное время, даже если этот сайт выключен. Аккаунт должен быть владельцем канала или администратором с правом публикации. Данные для входа хранятся на сервере в зашифрованном виде. Без этого шага посты можно публиковать только сразу.

    1. Получите ключи (один раз для всего сайта). Откройте my.telegram.org/apps, войдите по номеру телефона (код придёт в Telegram), нажмите «Create application» (название и короткое имя любые, платформа — Desktop) и скопируйте api_id и api_hash.
    2. Войдите в аккаунт. Введите ключи и номер телефона владельца канала и нажмите «Получить код»: код придёт в Telegram (чат «Telegram»). Если код не приходит — «Войти по QR-коду»: Telegram на телефоне → Настройки → Устройства → Подключить устройство.
    1. Откройте Telegram на телефоне: Настройки → Устройства → Подключить устройство.
    2. Наведите камеру на этот код. Он обновляется сам.
