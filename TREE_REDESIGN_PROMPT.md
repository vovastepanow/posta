# Задача: переделать вкладку «Дерево» — новый дизайн в стиле приложения и хэштеги у тем

Ты работаешь в проекте `/var/www/html/posta` (Posta). Владельцу не нравится вкладка «Дерево» («хуйня полная»): это 23 одинаковые серые рамки
с серыми таблетками, без характера, без иерархии, а справа — сырые поля базы. Ещё нужно, чтобы **у тем показывались хэштеги**.

Ничего не коммить. Модели не вызывать. Поведение (выбор темы, «Сделать текущей», смена общей темы, сброс профиля) — сохранить.

## 2. Хэштеги

### 2.1 Наполнить словарь
Для **каждой частной темы дерева** (все ключи из `lib/taxonomy/*.php`, кроме `*.other`) — 6–15 хэштегов в файл своей ветки
`data/taxonomy/hashtags/<ветка>.tsv` (`humor.tsv`, `animals.tsv`, …; формат и `internet.tsv` — образец).
- Так, как их реально пишут в русскоязычных Telegram/VK/TikTok: `#шитпост`, `#сюр`, `#проклятые_картинки`, `#котики`, `#кототерапия`…
  Англоязычные — только если они в ходу и у нас (`#cursed`, `#brainrot`). Без общих пустых (`#юмор` у каждой темы юмора не нужен — он у общей).
- В синонимы — варианты написания (слитно/через `_`, ё/е, транслит), их нормализует `hashtag_norm`.
- Тег может относиться к двум темам (через запятую), но не к пяти.
- Темы 18+ / «Жесть» (`nsfw`) — хэштеги нейтральные, без мата и порнословаря.
- `php tools/cli.php taxonomy-check` — зелёный. Сколько тегов вышло по веткам — в отчёт.

### 2.2 Отдать в интерфейс
- `topic_public()`: поле `hashtags` — канонические теги темы из словаря (по ключу темы; у общей темы — объединение тегов её детей **не** нужно,
  только свои, если есть). У тем без ключа (созданных пользователем) — пустой список.
- Если словарь большой — кэшируй обратный индекс «ключ темы → теги» на запрос (как `hashtag_dictionary`), не перебирай словарь на каждую тему.

## 3. Новый дизайн

Цель: дерево читается как **программа передач / витрина рубрик**, а не как список рамок. Сначала сделай разметку-стенд (см. §4) и сравни с текущим.

### 3.1 Каркас (широкий экран ≥ 1100 px)
Три колонки: **рубрики** (≈260 px) | **темы выбранной рубрики** (гибкая) | **паспорт темы** (≈360 px, липкий).
- Слева — список 23 общих тем, как «каналы» в телегиде: строка = эмодзи-значок рубрики + название Oswald капсом + число частных тем.
  Выбранная — жёлтая плашка с чёрной обводкой и тенью `--shadow-btn`; рубрика текущей темы — с красной меткой «В ЭФИРЕ» (как `.air-ticker-tag`).
  Значки рубрик — эмодзи, словарь в JS по ключу ветки (`humor` 😂, `animals` 🐾, `news` 📰, …; нет в словаре — 📁).
- По центру — заголовок рубрики (Oswald, крупно) + её `about` + **карточки частных тем** сеткой `repeat(auto-fill, minmax(220px, 1fr))`:
  карточка — белая поверхность, `var(--border) solid var(--line-strong)`, `--radius-card`, при наведении сдвиг −2 px и тень `--shadow-card`.
  Внутри: название (Rubik 600, 16 px), одна строка `about` (обрезка в 2 строки), снизу — до 3 хэштегов чипами `#тег` (шрифт `--font-tag`) и «+N»,
  в углу — число своих источников (иконка + число; 0 — «источники общей темы» серым).
  Текущая тема — жёлтая заливка карточки + «📍 В ЭФИРЕ». Темы 18+ — пометка «18+» красной плашкой.
  Первой карточкой — сама общая тема («Вся рубрика»), её тоже можно выбрать.
- Справа — **паспорт темы** (см. 3.2).

### 3.2 Паспорт темы
- Хлебные крошки «Мемы и юмор › Абсурдный юмор», название крупно, плашки: общая/частная, 18+, «📍 сейчас выбрана».
- Кнопка «Сделать текущей» — главная (жёлтая, на всю ширину). «Сменить общую тему» и «Пересоставить профиль» — вторичные, мельче.
- «О теме» — абзац. **Хэштеги** — все чипами (клик копирует `#тег` в буфер, короткое «Скопировано»). Нет хэштегов — строки нет.
- Другие названия (`aliases`) — серыми чипами.
- Блок «Как ИИ отбирает» — `<details>`, свёрнут: «Подходит», «Не подходит», «Вопрос к картинке», дата профиля, «составлен умной/быстрой моделью».
- Источники: «12 своих источников» / «своих нет — берутся источники общей темы».
- «Полная запись из базы» — убрать с глаз: `<details>` «Для отладки» в самом низу, грузится только при раскрытии (сейчас грузится сразу).

### 3.3 Поиск по дереву
Поле над колонками (вместо нынешней формы, её функция сохраняется): ввод фильтрует **на лету** рубрики и карточки по названию, `about`, синонимам
**и хэштегам** (`#сюр` или `сюр` → «Абсурдный юмор»; используй ту же нормализацию, что `hashtag_norm`: строчные, ё→е, пробел/дефис→`_`).
Совпадения подсвечиваются (`<mark>`), рубрики без совпадений скрываются, у рубрик — число найденных. Enter — как сейчас: перейти к теме
или создать новую (подтверждение `TOPIC_CONFIRM` и «Нет, это другая тема» — сохранить). Esc — очистить поле.
Легенду `.tree-legend` убрать — всё должно быть понятно без неё (подсказки — `title`).

### 3.4 Узкий экран и телефон
- 700–1100 px: рубрики сверху горизонтальной лентой-прокруткой (чипы-вкладки), ниже карточки, паспорт — под карточками.
- Телефон (390 px): лента рубрик, карточки в одну колонку; нажатие на карточку открывает паспорт **нижним листом** (`position: fixed`, до 85vh,
  своя прокрутка, ✕ и закрытие по Esc/клику по фону), фон не прокручивается.
- Нет горизонтальной прокрутки страницы ни на одной ширине.

### 3.5 Общее
- Только токены темы — обе темы (День и Эфир) должны выглядеть родными. Никаких новых цветов кроме токенов.
- Состояние (выбранная рубрика и тема) — в `tree` как сейчас; выбор рубрики запоминай в `localStorage` (в `try/catch`).
- При открытии вкладки — выбрана рубрика текущей темы и сама текущая тема.
- Доступность: рубрики и карточки — `<button>`, у списка рубрик `role="tablist"`/`tab` или просто кнопки с `aria-pressed`; фокус видно (`:focus-visible` — обводка `--accent`).
- Перерисовка при фильтре — без мигания и потери фокуса в поле.

## 4. Проверка

- **Не открывай боевую страницу** (`http://localhost/posta/`) в headless как нового пользователя: свежая загрузка создаёт пользователя и запускает парсер.
  Делай стенд: копия разметки вкладки + `css/app.css` + модуль, а `api('topics')` подменён сохранённым ответом (сними его один раз через
  `php -r` из `handle_topics`/`topic_public` в JSON-файл в `tools/fixtures/`). Дерево в демо-режиме не показывается (`DEBUG_MODE`) — демо не подходит.
- Chrome: `google-chrome --headless=new --no-sandbox --jitless --window-size=1440,900` и 1920×1080, 1000×800; телефон — `iframe 390×844`
  (окно headless меньше 500 px не бывает). Темы День и Эфир. CDP через встроенный в Node 22 `WebSocket`, пакеты не ставить.
- Сценарии: выбор рубрики; выбор темы → паспорт; поиск «сюр», «#cursed», «кот» — нужные карточки и подсветка; «Сделать текущей» (на стенде — что ушёл
  правильный запрос); телефон — нижний лист открывается и закрывается.
- Снимки «до» (текущее дерево на том же стенде) и «после» — в отчёт.
- `php -l`, `taxonomy-check`, консоль браузера без ошибок. `node --check` недостаточно.
