# Posta

Собирает картинки, видео и посты по теме из Telegram, VK, Двача, 4chan, TikTok, YouTube и сайтов, отбирает их моделью ИИ,
показывает карточками и публикует понравившееся в ваш Telegram-канал (и в другие соцсети) сразу или по расписанию.

Один бинарник на Go (`posta`): сайт и JSON API, сборщики, публикатор, радар лидов, клиент Telegram-аккаунта (MTProto).
Данные — Postgres, аналитика (вызовы моделей, оценки, журнал сборщика, публикации) — ClickHouse. PHP, Python и Node не нужны.
Устройство — `docs/ARCHITECTURE.md`.

## Требования

- Go 1.26 (сборка), Postgres 16+, ClickHouse (необязательно: без него просто не пишется аналитика).
- Ollama на `localhost:11434` (локальные модели: `qwen3-vl:2b-instruct`, `qwen3.5-vision:latest`, `bge-m3`) и/или ключ OpenRouter.
- `ffmpeg`/`ffprobe`, Google Chrome (поиск TikTok), `tools/bin/yt-dlp` и `tools/bin/deno` — `sh tools/update-tools.sh`.

## Настройка

Все секреты и адреса — в `posta.env` рядом с бинарником (права 600, в git не попадает):

```
POSTA_LISTEN=127.0.0.1:8090
POSTA_BASE_PATH=/posta              # если сайт за прокси в подпапке
POSTA_PG=postgres://posta:ПАРОЛЬ@127.0.0.1:5432/posta?sslmode=disable
POSTA_CH=127.0.0.1:9000             # пусто — без ClickHouse
POSTA_MEDIA_DIR=/var/lib/posta/media
POSTA_MEDIA_URL=media
POSTA_DATA_DIR=/var/lib/posta/data
POSTA_SECRET_KEY_FILE=/var/www/html/posta/secret.key.php   # ключ шифрования токенов (прежний файл PHP подходит)
POSTA_PUBLIC_URL=https://домен/posta
OPENROUTER_API_KEY=…
```

```
go build -o bin/posta ./cmd/posta
bin/posta migrate                               # схема Postgres и ClickHouse
bin/posta import-sqlite data/posta.sqlite <id>  # один раз: перенос из прежней базы SQLite (только владелец + общие данные)
bin/posta serve
```

Развёртывание на сервере (Postgres, ClickHouse, systemd, прокси Apache) — `sudo sh deploy/install.sh`.

## Как это работает

- **Вход.** Профиль — сессия в куке. Логин и пароль задаются в «Кабинет → Профиль», второй способ — бот входа Telegram
  (`posta login-bot-from-channel <id>`). Забыли пароль — `posta user-password <id|логин>`. Новые профили не создаются,
  пока в админке («Поведение → Новые пользователи») это не включено.
- **Модели.** У каждой задачи (быстрый отсев, полный анализ, судья, «умные» задачи, тексты, радар, перевод, эмбеддинги) своя
  модель и резерв: Ollama или OpenRouter. Наборы: «Бесплатно» (по умолчанию: отсев локально, анализ — бесплатная модель
  OpenRouter, резерв — Ollama), «Только свой компьютер», «Гибрид», «Облако». Платные модели не вызываются, пока дневной бюджет 0.
  Всё переключается в админке → «Модели»; расход виден там же.
- **Поведение.** Параметры сборщика, отбора, подбора источников, видео, публикации и значения по умолчанию для пользователей —
  в админке → «Поведение»: действуют сразу для всех, без перезапуска.
- **Отбор.** Посты источников темы → быстрая оценка маленькой моделью → полный анализ лучших (видео — раскадровкой)
  → в ленту, если «по теме» не ниже порога модели.
- **Темы.** Дерево: 26 веток, 124 темы; у темы — рубрика-хэштег, синонимы, сущности, формат (картинка/текст/видео).
- **Публикация.** Бот публикует сразу; очередь Posta — по времени или в слот расписания канала (горутина-публикатор);
  «Отложенные» Telegram — через личный аккаунт. Другие соцсети — адаптеры (`internal/posta/networks.go`).
- **Студия** (`studio.html`) — обзорная страница: лента отобранного, источники, работа модели, быстрые действия.

## Команды

`posta help` — список: владелец (`owner`), пароль, бот входа, 18+, баланс, фильтр Украины, прогон автоподбора, радар,
ремонт очереди и медиа, уборка профилей, набор моделей.
