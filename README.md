# Posta

Собирает картинки и видео по теме из Двача, Telegram и ВКонтакте, оценивает их локальной vision-моделью (Ollama),
показывает отобранное карточками и публикует понравившееся в ваш Telegram-канал.

## Требования

- PHP 8.1+ (curl, json, mbstring, GD, sodium), Apache с `AllowOverride All` для папки сайта: `sudo sh tools/apache-setup.sh`.
- Ollama на `localhost:11434`: основная модель `qwen3.5-vision:latest`, быстрая — `ollama pull qwen3-vl:2b-instruct`
  (список `PRESCREEN_MODELS` в `config.php`); для проверки «та же тема» — `ollama pull bge-m3` (необязательно).
- `ffmpeg`/`ffprobe` — раскадровка видео и перекодирование для браузера и Telegram. `python3` — отложенные посты через аккаунт.

## Настройка

1. `config.local.example.php` → `config.local.php`, VK-значения (Redirect URI: `https://ДОМЕН/index.php?action=vk_oauth_callback`).
2. Данные (база `data/posta.sqlite`, `media_cache/`, журналы парсера в `users/`) создаются сами; веб-серверу нужны права на запись в папку сайта.
3. Cron: `* * * * * sh tools/fix-permissions.sh` и (по желанию) ночной подбор `0 4 * * * php tools/cli.php nightly-discovery`.

## Как это работает

- **Сессия вкладки.** Открытая вкладка запускает фоновый сборщик (`cron_parser.php`) своего пользователя; закрытие или
  150 с без сигнала останавливают его. Одновременно — не больше `MAX_PARALLEL_PARSERS` сборщиков.
- **Вход.** Профиль — сессия в куке. Свой логин (почта, телефон или ник) и пароль задаются в «Кабинет → Профиль»; вход через
  Telegram (бот входа, `cli.php login-bot-from-channel`) — второй способ. Забыли пароль — `cli.php user-password <id|логин>`.
- **Пользователи.** Кука `ct_uid` → папка `users/<id>/` (пул, история, настройки, журнал). Каталог источников и кэши общие.
- **Отбор.** Посты источников темы → быстрая оценка «да/нет» маленькой моделью (вероятность «да») → полный анализ лучших
  (видео — листами раскадровки 2×2) → в пул, если «по теме» ≥ `RELEVANCE_THRESHOLD`. Медиа сохраняются в `media_cache/`.
- **Темы.** Реестр тем (общие и частные) с профилем от умной модели: критерии, вопрос для быстрой оценки, план поиска.
  Можно задать вторую тему — запись должна подходить под обе.
- **Источники.** Автоподбор: поиск и «похожие каналы» Telegram через подключённый аккаунт, поиск VK, ссылки из каналов темы.
  Оценка = по теме 45% + аудитория 25% + доля просмотров 30%; мёртвые каналы и треды замораживаются. Находки решает пользователь.
- **Публикация.** Бот (Bot API) — сразу; отложенные посты — через личный аккаунт в «Отложенные» канала. Токены и сессии
  хранятся зашифрованными (`secret.key.php`). Лимит размера видео уточняется по ответам Telegram.
- **Память модели.** Разросшийся процесс Ollama перезапускается выгрузкой модели (`lib/ai.php`).
- **Демо-режим** — кнопка «🐞 Демо» в журнале (`?debug=1`): тестовые записи в PHP-сессии, файлы и модель не трогаются.

## Очередь публикаций и cron

Отложенные посты Posta хранит у себя и публикует через бота, даже если аккаунт Telegram не подключён.
Публикатор (`tools/publisher.php`) должен запускаться по расписанию. От какого пользователя — от того же, что веб-сервер
(публикатору нужны права на запись в `data/` и `users/`, как у сайта). Добавьте строку:

```
sudo crontab -u www-data -e
* * * * * /usr/bin/php /var/www/html/posta/tools/publisher.php >> /var/www/html/posta/users/publisher.log 2>&1
```

Без cron посты уходят, только пока открыта вкладка сайта: вкладка сама запускает публикатор, если есть созревшие посты.
Журнал публикатора: `users/publisher.log`. Файлы отложенных постов лежат в `data/outbox/`; лишние папки
удаляет `php tools/cli.php outbox-gc`.

## Структура

| Путь | Что внутри |
|---|---|
| `index.php` | JSON API: таблица действий, CSRF-заголовок `X-Posta`, демо-режим |
| `cron_parser.php` | точка входа фонового сборщика |
| `config.php` | все пороги и настройки |
| `lib/db.php`, `lib/db_access.php` | SQLite (`data/posta.sqlite`): миграции и доступ к данным |
| `lib/core.php` | пользователи, HTTP, шифрование, настройки |
| `lib/billing.php` | тарифы, баланс в рублях, приглашения |
| `lib/ai.php` | Ollama, присмотр за памятью, промпты и разбор ответов |
| `lib/sources.php` | Двач, Telegram, VK, каталог, активность и качество источников |
| `lib/topics.php`, `lib/discovery.php` | реестр тем и автоподбор источников |
| `lib/content.php` | пул, история, кэш медиа, видео, живость тредов |
| `lib/telegram.php` | публикация, лимиты, личный аккаунт (`tools/tg_user.py`) |
| `lib/runtime.php`, `lib/parser.php` | запуск сборщика, сессия вкладки и сам сборщик |
| `handlers/` | обработчики API по вкладкам |
| `js/`, `css/app.css`, `index.html` | интерфейс на ES-модулях без сборки |
| `tools/cli.php` | утилиты: `php tools/cli.php` покажет список команд |

Журнал сборщика: `users/<id>/parser-v3.log` (его же показывает консоль сайта).
