# Рабочая связка Nemotron → Qwen, 13 ноября 2026

Обновление развёрнуто в Posta, служба перезапущена. API подтвердил отсутствие
Baidu во всех ролях и следующие настройки:

- `classify`: `nvidia/nemotron-3.5-super-vl:free`, резерв `qwen/qwen3.7-flash`.
- `classify_verify`: `qwen/qwen3.7-flash`, предпочтение `alibaba/us-east-1`.
- Общий суточный бюджет не повышен: $0.10. Проверочный предел: $0.02.

Qwen используется для смысловой проверки каждого предложения тем, а не только
после сетевой ошибки Nemotron. При недоступности Nemotron Qwen может выполнить
также этап предложения. Чувствительные записи по-прежнему не отправляются
внешнему классификатору. При недоступности проверки сохраняется pending;
неподтверждённые метки не подменяют отрицательный вердикт.

## Исправления

1. Добавлена отдельно настраиваемая роль проверки тем. Разрешён явно назначенный
   платный маршрут при сохранении ценовых ограничений, общего бюджета и
   атомарного резерва классификации. Бесплатные установки без отдельного
   проверяющего сохраняют прежний маршрут.
2. Совпавшей цитаты недостаточно: требуется раскрытый аспект определения;
   отрасль участника, хештег и соседняя тема не становятся метками автоматически.
   Одно одинаковое обоснование для разных тем оставляет неопределённость.
3. Несколько согласованных строк об одной теме объединяются. Это исправило
   налоговую публикацию: Qwen подтвердил два налоговых факта отдельными строками
   и явно отклонил личные финансы. Все положительные цитаты проверяются;
   противоречивые строки, отсутствующие кандидаты, неизвестные ключи и выдуманные
   цитаты не принимаются. Повреждённые JSON-обёртки не восстанавливаются для применения.
4. Для 429 общего пула поставщика убраны немедленные повторы также у платных
   моделей. Первоначальный Qwen вернул `insufficient_quota` от Alibaba; после
   настройки предпочтения регионального endpoint четыре контрольных запроса
   завершились успешно. Это не гарантия постоянной доступности поставщика.

Поддержка предпочтений endpoint и список регионов проверены по
[документации OpenRouter](https://openrouter.ai/docs/guides/routing/provider-selection)
и [каталогу endpoint Qwen 3.7 Flash](https://openrouter.ai/api/v1/models/qwen/qwen3.7-flash/endpoints).

## Контроль качества и границы

| Пример | Итог |
|---|---|
| Иски к рекламной группе, 17896 | Право; маркетинг отклонён |
| Поведение поколений покупателей, 17885 | Маркетинг; общество и социальные вопросы отклонены |
| Налоговая экономия Apple, 17889 | Налоги; личные финансы отклонены |
| Самостоятельные разборы рекламного теста и процесса продажи | Маркетинг + Продажи, обе сохранены |
| Судебное взыскание у компании медицинской отрасли | Право; отрасль не стала темой |
| «Всё в видео», без содержимого | Неопределённость, метки не назначены |

На этих пяти содержательных примерах получены ожидаемые наборы; шестой случай
корректно остался неопределённым. Это три публичных регрессионных публикации и
три специально составленных контроля, не независимая оценка всего каталога.
Для медиа использовано сохранённое описание, не новый анализ видео.

Предложения Nemotron переиспользованы из сохранённых ответов. Проверки Qwen
получены реальными запросами; исправленный разбор повторных строк проверен
локальным воспроизведением этих ответов, без повторной оплаты. Точные ответы
включены в `tools/fixtures/classification_live_replay.json`; тесты воспроизводят
обе роли и отдельно проверяют противоречия, пропуски и ложные цитаты.

Дополнительно проверен установленный `bin/posta classify-text` на новом
юридическом тексте. Nemotron ответил 429, платный резерв Qwen предложил тему,
Qwen выполнил окончательную проверку; процесс завершился с кодом 0 и
`business.legal`. Команда не сохраняет метки. Это проверка настоящего бинарника,
его конфигурации, доступа к API и бюджетного пути, а не только подставного сервера.

Первый запуск установленного бинарника был остановлен консервативным лимитом
проверочного прокси после успешного платного предложения. В продолжении уже
известные расходы успешных запросов учтены вместо максимальных резервов;
для ошибочного запроса сохранён верхний резерв. Общий предел $0.02 не повышался.
