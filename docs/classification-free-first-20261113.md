# Бесплатная классификация и платный резерв

По уточнению пользователя обе роли `classify` и `classify_verify` настроены
одинаково: основной маршрут `nvidia/nemotron-3.5-super-vl:free`, резерв
`qwen/qwen3.7-flash`. Резерв вызывается при недоступности бесплатного маршрута
или сообщении поставщика об исчерпании квоты, если денежный бюджет позволяет.
На ответ бесплатной модели, который не прошёл смысловую проверку, платная модель
автоматически не вызывается: результат остаётся неопределённым.

Настройки изменены с проверкой конкурентных изменений. Бюджеты и метки не
менялись, перезапуск не требовался; работающий API подтвердил обе роли.
Контрольный снимок: `data/backups/classification-free-first-20261113/`.
После изменения прежние метки пула совпали, старые связи каталога не удалены.

Платный резерв классификации на момент проверки был исчерпан. Поэтому при
недоступности Nemotron Qwen до освобождения бюджета не сработает; подходящие
записи остаются с неопределённой классификацией. Счётчик не обнулялся.

## Проверка

- Установленный `bin/posta classify-text` вернул `finance.banks` для новости
  о переводах, несмотря на исчерпанный платный резерв.
- В аудит повторно отправлены два ранее заблокированных текста. Оба этапа обеих
  записей выполнил бесплатный Nemotron: для изменения контроля над акционером
  Ozon предложено `business.owners` вместо прежней `finance.invest` (спорное
  предложение не применено); для переводов подтверждена `finance.banks`.
- Новых платных вызовов при проверке не было. Результаты аудита записаны в
  `data/backups/classification-new-text-check-20261113/review.jsonl`.
- Тест `TestClassifierUsesFreeVerifierWithExhaustedPaidBudget` подтверждает,
  что оба этапа работают бесплатно даже при нулевом денежном бюджете;
  scoped Go-тесты бюджетной маршрутизации прошли.

Отчёт `classification-nemotron-qwen-20261113.md` описывает прежнюю конфигурацию,
где Qwen был обязательным проверяющим; она заменена этим вариантом.
