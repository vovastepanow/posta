# Задача: клик по превью в карточке предложенного источника открывает карточку поста

Проект `/var/www/html/posta` (Posta). Фронтенд — ES-модули без сборки, тексты интерфейса по-русски, комментарии по-русски
одной строкой. Не делай `git commit`. **Не открывай сайт** (`http://localhost/...`) ни curl, ни браузером: каждая
загрузка без куки создаёт пользователя и запускает парсер. Проверяй через `node --check` и стенд (см. «Проверка»).

## Что хочет владелец (его слова, сжато)

На вкладке «Источники» карточка предложенного источника показывает превью его постов (картинки). По нажатию на
картинку должна открываться **карточка поста** с этим превью:
- фон за ней **легко затемнён** (полупрозрачная подложка, не чёрная);
- карточка поста лежит **поверх карточки источника** и **чуть смещена в сторону**, так что карточка источника
  **видна под карточкой поста** (не полностью закрыта);
- по клику на подложку, по крестику и по Escape карточка закрывается.

## Где что лежит

- `js/sources.js`:
  - `topicSourceCard(source)` (около строки 314) — строит карточку предложенного источника. Превью:
    `const slides = source.preview.map(src => ({ kind: 'image', src, poster: src, sourceUrl: source.url, alt: source.name }));`
    и мозаика `el('div', { className: \`proposal-media mosaic-${slides.length}\` })`, тайлы — дальше по функции.
  - `renderTopicSources()` (около строки 366) — перерисовывает список карточек.
  - `initializeSourceTab()` (около строки 716) — вешает обработчики вкладки.
- `js/viewer.js`: `openViewerGallery(items, index, onPost, postCheck)` (строка 214) — существующий просмотрщик
  на весь экран. **Не переиспользуй его**: он на весь экран и не даёт видеть карточку источника под собой.
- `css/app.css`: классы карточек источников (`proposal-card`, `source-tile-card`, `source-head`, `source-chips`)
  и мозаики (`proposal-media`, `mosaic-N`, `proposal-tile`). Уже есть правило для текстовой плитки:
  `.proposal-tile.is-text` — не ломай его.

## Что сделать

1. **Клик по превью.** Каждый тайл превью (картинка) в `topicSourceCard` получает обработчик клика: открыть
   карточку поста для этого превью. Клик по тайлу не должен открывать ничего другого (кнопки «Открыть ↗» и
   «Включить» на карточке остаются как есть).
2. **Карточка поста.** Новая функция в `js/sources.js`, например `openSourcePreview(source, index)`:
   - собирает оверлей: `div.source-preview-overlay` (на весь экран, `position: fixed`, фон
     `rgba(17, 17, 17, 0.25)` — лёгкое затемнение, цвет из переменной `--modal-dim` не брать: он слишком тёмный);
   - внутри — `div.source-preview-card` с картинкой превью (`img`, `alt` = название источника, `loading="lazy"`),
     подписью источника (название и ссылка «Открыть пост ↗» на `source.url`, `target="_blank"`, `rel="noopener noreferrer"`)
     и кнопкой «✕» (`aria-label="Закрыть"`);
   - если у источника несколько превью — стрелки «←» и «→» по кругу; индекс показываем текстом «2 из 4».
3. **Положение.** Карточка поста — поверх карточки источника и **сдвинута вправо и вниз**, чтобы нижняя и
   правая части карточки источника оставались видны:
   - берём прямоугольник исходной карточки источника (`getBoundingClientRect()` её `article`);
   - позиционируем карточку поста: `left = rect.left + 24px`, `top = rect.top + 24px`, ширина `min(rect.width * 0.85, 420px)`;
   - если карточка поста не помещается в окно, сдвигаем её в пределах экрана (отступ 8px со всех сторон);
   - при изменении размера окна (`resize`) — пересчитать; на узком экране (≤ 600px) — карточка по всей ширине
     с отступом 12px, без сдвига, но её нижняя часть не должна закрывать весь источник (допустимо, что источник
     виден только под краем: это мобильный вариант).
4. **Закрытие.** Клик по подложке (не по карточке), кнопка «✕», клавиша Escape (слушатель на `keydown` добавляется
   при открытии и снимается при закрытии). Закрытие удаляет оверлей из DOM и снимает слушатели.
5. **Без утечек.** При повторном открытии предыдущий оверлей удаляется. Все пользовательские строки (название
   источника, подпись) — только через `textContent`/`el()`, никакого `innerHTML` с данными источника.
6. **Стили.** Добавь в конец `css/app.css` блок `/* ---- Превью источника: карточка поста поверх карточки источника ---- */`.
   Только переменные темы (`--surface`, `--line-strong`, `--radius`, `--shadow-card`, `--text`, `--muted`),
   без захардкоженных цветов кроме подложки. Тень карточки — `var(--shadow-card)`. Тёмная и светлая темы
   переключаются сами.

## Ограничения

- Не меняй API, `handlers/`, `lib/` и `index.php`.
- Не трогай `openViewerGallery` и его вызовы.
- Не добавляй библиотек и сборки.
- Код в стиле `js/sources.js`: короткие функции, `const`/стрелочные, без классов.
