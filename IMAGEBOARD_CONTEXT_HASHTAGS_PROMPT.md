## Часть A. Тред, шапка и заголовок как контекст анализа

### Что выяснено (перепроверять не нужно)

- **Двач.** `parse_dvach` (`lib/parser.php:14`) берёт до `DVACH_THREADS_PER_BOARD` свежих тредов доски и медиа-посты
  каждого. Запись: `text`/`captions` — текст **ответа** (`dvach_post_text`), `source` — «Двач /b/ · <название треда>».
  **Шапки треда (текст ОП-поста) в записи нет**, название треда есть только внутри строки `source`.
- **4chan.** `fourchan_thread_media` (`lib/fourchan.php:191`): то же. `sub` (тема треда) попадает только в текст
  самого ОП-поста (`fourchan_post_text`, строки 158–159), у ответов темы нет. `fourchan_preview` вызывает с `'sub' => ''`.
- **Промпт полного анализа** `content_analysis_prompt` (`lib/ai.php:378`) получает `$source = $item['source']` и
  проверяет `$source !== 'Двач'`, чтобы не давать подпись Двача. **Проверка никогда не срабатывает**: там строка
  «Двач /b/ · …». Сейчас подпись ответа идёт в промпт всегда, как обычная подпись поста, а контекста треда нет совсем.
- **Треды не отбираются по теме.** В /b/ большинство тредов не про тему подборки, но посты каждого гоняются через
  быструю оценку картинки. Тред «Абсурдные картинки тред #47» почти весь по теме, но это нигде не используется.
- Быстрая оценка (`quick_relevance_score`, `lib/ai.php:655`) получает картинку и подпись, о треде ничего не знает.
- **Статьи** (vc.ru, dtf.ru и новостные сайты: `lib/news.php`, `lib/osnova.php`, `lib/rss.php`): у записи есть
  `article` (`title`, `lead`, `site`, `rubric`). Текстовые посты оцениваются `analyze_text_candidate`
  (`lib/parser.php:631`) → `analyze_text_batch([$text], $topic)`, то есть по `text`. Проверь, есть ли в этом `text`
  заголовок статьи и стоит ли он первым. Для статьи с картинкой картинка — часто обложка, а не содержание.

### Что сделать

1. **Поля контекста в записи.** У постов Двача и 4chan добавь `thread_title` (название или тема треда, без HTML,
   до 120 символов) и `thread_op` (текст ОП-поста, очищенный тем же `dvach_post_text` / `fourchan_post_text`, до 400
   символов). У самого ОП-поста `thread_op` не нужен (он и есть `text`), поставь `is_op => true`. В `fourchan_preview`
   передавай настоящую тему треда (возьми из `fourchan_threads` или из ОП-поста треда), а не пустую строку.
2. **Отбор тредов по теме** (только Двач и 4chan, в парсере). Перед тем как брать посты треда, оцени тред по
   `thread_title` и `thread_op` **одним текстовым вызовом на пачку тредов доски** через быструю модель
   (`prescreen_model()`, JSON `{"scores": [числа]}`, как `quick_source_text_score` в `lib/discovery.php:98`).
   Вопрос: «Посты этого треда — по теме подборки?» 0–100. Тема — `topic_prompt_context` + `topic_profile_hint`.
   - тред ниже `THREAD_TOPIC_SKIP = 20` — посты не берём (в консоль: «тред „…“ не по теме (N) — пропуск»);
   - выше `THREAD_TOPIC_TRUST = 70` — посты треда идут в анализ первыми, а порог быстрой оценки картинки для них ниже
     на `THREAD_TRUST_PRESCREEN_BONUS = 10` (найди, где сравнивается `PRESCREEN_THRESHOLD`);
   - между ними — как сейчас.
   - Пустая шапка и безымянный тред (в /b/ это часто) — оценки нет, тред идёт как сейчас.
   - Кэш оценки треда — `kv` `thread_topic:<тема_norm>:<board>:<thread>` на сутки, чтобы следующий проход не звал модель снова.
3. **Промпт полного анализа.** В `content_analysis_prompt` вместо сломанной проверки `$source !== 'Двач'` смотри на
   площадку записи (`content_source_key($item)` начинается с `dvach:` или `4chan:`; передай в функцию `$item` или
   готовый блок контекста, а не строку `source`). Для имиджборд:
   - «Пост из треда имиджборды. Тред: «<thread_title>». Шапка треда (о чём тред): <thread_op>.» Тред задаёт тему
     постов: картинка в треде «абсурдные картинки» — скорее всего абсурдная картинка.
   - Текст ответа подавай как «Текст ответа в треде (часто реакция на другие посты, может не относиться к картинке)»,
     до 300 символов, без `>>12345`.
   - Блок контекста ставь **после** неизменной части промпта (перед «Запись:»), чтобы не ломать кэш префикса Ollama
     (см. комментарий над функцией).
4. **Быстрая оценка.** В `quick_relevance_score` для имиджборд добавь одну строку «Тред: «…».» (только название, без
   шапки: быстрый промпт должен оставаться коротким).
5. **Статьи.** В `analyze_text_candidate` и пакетной оценке текста для записей с `article`: текст для модели —
   «Заголовок статьи: …\nПодзаголовок: <lead>\nРубрика: … · Сайт: …\n<начало текста>», заголовок первым. Если у
   статьи есть картинка-обложка и она идёт через полный анализ картинки, в промпт передавай тот же блок вместо подписи
   и поясни модели: «картинка — обложка статьи, судить по заголовку».
6. Кэш анализа: в `analysis_cache_key` тема уже входит. Кэш **не сбрасывай** целиком. Новые записи имиджборд получат
   новый промпт, старые доживут своё.

### Проверка A

- `php -r` с `bootstrap.php`: собери `parse_dvach('b')` (или маленькую доску, если /b/ долго) и выведи по 3 записи:
  `thread_title`, `thread_op`, `is_op`, `source`.
- Выведи промпт `content_analysis_prompt` для записи Двача и для записи Telegram. У Двача есть блок треда, у Telegram
  ничего не изменилось, побайтно до «Тема подборки:».
- Отбор тредов: на 10 тредах доски выведи оценки и решения (пропуск / доверие / как раньше), модель вызвана один раз.
- Тест `tools/test_imageboard_context.php` (стиль `$check(...)` как в `tools/test_news_4chan.php`): поля контекста,
  проверка площадки по `source_key`, у Telegram промпт без блока треда, пороги отбора.
