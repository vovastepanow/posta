# Задача: переделать просмотрщик постов — листание по бокам окна, медиа втрое меньше, все медиа сразу сеткой

Ты работаешь в проекте `/var/www/html/posta` (Posta). Просмотрщик постов уже есть (`POST_VIEW_PROMPT.md`, этап 1), но владельцу он не нравится:
огромная тёмная сцена на 2/3 окна, одно медиа за раз, лента миниатюр, стрелки листания постов спрятаны в шапке. Нужно:

1. **Кнопки листания постов — по бокам от окна просмотрщика**, снаружи карточки, а не в шапке.
2. **Медиа примерно в 3 раза меньше**, чем сейчас: это пост, а не фотовьювер. Крупно смотреть — через зум (`viewer.js`).
3. **Все медиа поста сразу, красивой сеткой** (мозаика как альбом в Telegram), без листания по одному файлу, без ленты миниатюр,
   без кнопки «▦ Все N».

Ничего не коммить. Не меняй адаптеры (`js/post-adapters.js`), формат нормализованного поста и API `openPostView(posts, index, { actions, loadMore, onClose, title })` —
место вызова (`sources.js:105`) не должно заметить переделку.

## 2. Новая раскладка

### 2.1 Рамка и кнопки листания по бокам

- Окно `.pv-sheet` — **одна колонка-карточка шириной ~720 px** (`width: min(720px, 100% - 2 × (кнопка + зазор))`), высота — по содержимому,
  но не больше `100vh - 40px`; внутри своя вертикальная прокрутка (`.pv-body`). Тёмной сцены на всю высоту больше нет.
- Обёртка `.pv-frame` (flex, по центру экрана): `[‹]  [карточка]  [›]`. Кнопки `.pv-side-nav` — круглые 56 px, по вертикали по центру
  **экрана** (не карточки: не должны прыгать при смене поста разной высоты), зазор до карточки 16 px. Вид — токены темы:
  `var(--surface)`, `var(--border) solid var(--line-strong)`, `var(--shadow-card)`, при наведении — `var(--accent)` / `var(--accent-text)`.
  На первом/последнем посте соответствующая кнопка `disabled` (прозрачность 0.3), но место занимает — карточка не сдвигается.
- Клик по затемнённому фону вне карточки и кнопок — закрывает (как сейчас; проверь, что клик по кнопке листания не закрывает).
- Шапка: «Пост 3 из 24», название, ✕. **Кнопки `.pv-nav` из шапки убрать** (их работа переходит к боковым).
- Если окно уже, чем карточка + 2 кнопки (меньше ~900 px) — см. 2.5.

### 2.2 Порядок внутри карточки (все раскладки)

Как пост в ленте: строка источника (`sourceRow`) → **сетка медиа** (если есть) → текст → опрос → статистика (`statsRow`) →
«Копировать текст» → полоса действий (закреплена снизу карточки, `position: sticky; bottom: 0`) → «Открыть в источнике ↗».
Раскладка `media` больше не отдельная двухколоночная: это та же колонка, что `text`, только с сеткой. `article` — как сейчас
(обложка, мета, заголовок, анонс, блоки), только в новой рамке. Длинный текст прокручивается вместе с карточкой.

### 2.3 Сетка медиа (главное)

Сетка `.pv-mosaic` — во всю ширину колонки (~680 px), **высота всей сетки ≤ 360 px для 1–4 файлов** (сейчас медиа занимает ~800×780 —
отсюда «втрое меньше»). Скругление `var(--radius)`, зазор 4 px, фон пустых мест `var(--surface-2)`. Мозаика по числу файлов:

| Файлов | Раскладка |
|---|---|
| 1 | один файл в своих пропорциях: ширина до 100 %, высота до 360 px, `object-fit: contain` на фоне `--surface-2` (вертикальное 9:16 — узкое по центру, не растягивать) |
| 2 | две колонки, высота 280 px, `object-fit: cover` |
| 3 | слева один большой (2/3 ширины, на всю высоту 320 px), справа два друг над другом |
| 4 | 2×2, высота 360 px |
| 5–6 | верхний ряд 2 файла (высота 200 px), нижний 3 (высота 140 px) / 3+3 |
| 7+ | ровная сетка квадратов: 4 колонки (на телефоне 3), `aspect-ratio: 1`, **показываются все**, сколько бы ни было (20 — это 5 рядов по ~165 px; прокручивается вместе с карточкой) |

Реализуй через CSS Grid: класс `.pv-mosaic.n-1 … .n-6` и `.n-many`, `grid-template-areas`/`span` — без расчётов размеров в JS.
Место резервируется сразу (у плиток фиксированная высота / `aspect-ratio`), поэтому при загрузке картинок вёрстка не прыгает.
У одиночного файла — `aspect-ratio` из `width/height`, если они есть, иначе 16:9 до загрузки.

Плитка `.pv-cell` — `<button>`:
- картинка: `<img loading="lazy" decoding="async" referrerpolicy="no-referrer">`, при ошибке — запасной адрес `m.fallback`, потом плашка «Файл недоступен»
  (логика — из текущего `mediaNode`);
- видео: **постер** + метка «▶ 0:42» (`duration`) в углу, как `.pv-tile-mark`. В сетке видео **не проигрывается**;
- `pending` (видео качается): постер + плашка «Видео загружается…», `watchVideo` как в `pendingPlate`; когда готово — плитка становится обычным
  видео-плиткой (постер + ▶), без перерисовки остальной сетки;
- `unavailable` (большое видео): постер, метка «большое видео», по клику — не зум, а подсказка `BIG_VIDEO_NOTE` (тот же текст, как плашка поверх плитки
  или `title` + раскрытие под сеткой — на твой выбор, но текст должен быть виден на телефоне без наведения);
- только `page` без файла — плитка-ссылка «Смотреть на сайте ↗» (`target=_blank rel="noopener noreferrer"`).

**Клик по плитке** — `openViewerGallery` по **всем** открываемым файлам поста (картинки и видео с `src`), начиная с этой плитки.
Видео смотрят там, со звуком (громкость 0.33 — проверь, что `viewer.js` её ставит; если нет — не трогай `viewer.js`, напиши в отчёте).
После закрытия зума пост остаётся открыт, фокус возвращается на плитку.

### 2.5 Телефон и узкие окна (< 900 px)

- Карточка — весь экран (как сейчас), сетка во всю ширину, высоты из таблицы × 0.75, `n-many` — 3 колонки.
- Снаружи карточки места нет, поэтому боковые кнопки становятся **круглыми 40 px поверх карточки у краёв экрана** (отступ 6 px, по
  вертикальному центру, фон `var(--surface)` с прозрачностью ~85 %, рамка `--line-strong`). Пока пользователь прокручивает карточку,
  они прячутся (opacity 0, `pointer-events: none`) и появляются через 600 мс после остановки — чтобы не загораживать текст.
  Свайп влево/вправо по карточке (кроме сетки, кнопок, ссылок) по-прежнему листает посты.
- Полоса действий снизу — с `env(safe-area-inset-bottom)`.

### 2.6 Клавиатура и прочее — без изменений

←/→ — посты, Esc — закрыть (если открыт зум `viewer.js` — сначала его), ловушка фокуса Tab (боковые кнопки — внутри неё), `history.pushState`
(«назад» закрывает), после закрытия фокус на исходном элементе и прокрутка страницы на месте, предзагрузка первой картинки соседних постов,
`loadMore` на последнем посте, `prefers-reduced-motion`. Весь текст — `textContent`/`richText`, никакого `innerHTML` с текстом площадок.
Цвета — только токены темы; просмотрщик должен выглядеть родным в темах «День» и «Эфир». Плавная смена поста: короткий fade 120 мс
(не при reduced motion).
