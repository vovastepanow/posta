# Задача: автопостинг во все соцсети, куда это технически возможно

Ты работаешь в PHP-проекте `/var/www/html/posta`. Владелец: «надо подключить все соцсети, которые возможно подключить для
автопостинга». Второй раз (2026-10-24): «почему у нас из соцсетей только ВК и Телеграм подключаются? надо все подключить:
и ТикТок, и Инстаграм, и Дзен, и Одноклассники» — эти четыре обязательны: Дзен (часть B6), Одноклассники, Instagram и
TikTok (часть C) — с кодом, а не только пояснением. Сейчас публикация есть **только в Telegram**. Делай по частям A → B → C, после каждой проверяй и пиши
короткий промежуточный отчёт. Часть D — только интерфейс и пояснения, без кода публикации.

## Общие правила

- **Не делай git commit.** Перед миграцией базы: `cp data/posta.sqlite data/posta.sqlite.bak-networks`.
- **Telegram не должен сломаться ни на шаг.** После каждой части прогоняй существующие тесты публикации и очереди
  (`ls tools/test_*` — всё, где есть telegram, outbox, publish, calendar, mirror) и `php tools/test_hashtags.php`.
- **Факты об API сверяй по официальной документации** (WebFetch) **до** того, как пишешь код: ниже — то, что известно на
  2026-10-24, API меняются. Расхождение — делай по документации и отметь в отчёте.
- Секреты (токены, пароли приложений, ключи) — только зашифрованными (`secret_encrypt` / `secret_decrypt`), как токен
  бота. В ответах API и в логах — никогда.
- Ключи приложений владельца (client_id, client_secret) — в `config.local.php` / окружении, как `VK_CLIENT_ID`
  (`config.php:4`, `config.local.example.php`). Нет ключей — соцсеть в интерфейсе видна как «не настроено на сервере»,
  а не ломается.
- Не открывай приложение в headless-браузере (свежая загрузка = новый пользователь + парсер). Сеть — только для чтения
  документации и для тестов на реальных аккаунтах, **только если владелец дал ключи**. Без ключей — тесты на
  подставном HTTP (по образцу `outbox_process_due(..., $send)`, куда отправка передаётся функцией).
- Стиль как в окружающем коде: короткие русские `/** … */`, константы в `config.php` с комментарием.

## Что выяснено о текущем коде (перепроверять не нужно)

- Каналы: таблица `channels` (`lib/db.php`, миграции 8, 9, 12, 15): `platform` (всегда `telegram`), `token_enc`, `bot_id`,
  `chat_id INTEGER NOT NULL`, `UNIQUE (user_id, chat_id)`, `schedule`, `style`, `hashtags`. Чтение — `channel_from_row`,
  `channels_load`, `channel_get`, запись — `channel_save` (`lib/db_access.php`). Для других соцсетей `chat_id` и
  уникальность по нему не годятся.
- Публикация сразу: `handle_telegram_publish` (`handlers/account.php:403`) → `publish_channel_resolve` (`lib/telegram.php:91`,
  лимит каналов по тарифу `billing_limits`) → `telegram_prepare_media` → `telegram_publish_prepared`.
- Очередь: `outbox_queue_post` → публикатор `tools/publisher.php` → `outbox_process_due($now, 'outbox_send_post')` →
  `outbox_send_post($post, $channel)` (`lib/telegram.php:935`) — **единственная точка отправки**, сюда встаёт
  выбор адаптера по `platform`. Повторы и ошибки — `outbox_retry_or_fail`, `outbox_error_is_fatal`.
- Отложка средствами Telegram (`native`, через аккаунт) — только Telegram. Остальные соцсети ставят пост в нашу очередь
  (`queue` / `slot`), режим `native` для них не показывать.
- Редактор поста (`js/editor.js`): цели `tg:main` / `tg:<id>` (`channelTarget` в `js/content.js:476`), лимиты текста по
  префиксу цели — `TEXT_LIMITS` (`js/editor.js:75`, там уже есть `vk`), `MAX_MEDIA = 10`, опрос. Хэштеги — режим канала
  `hashtags` и `channel_hashtags()` / `text_with_hashtags()` (`lib/hashtags.php`).
- Подключение Telegram в интерфейсе: «Личный кабинет» → «Соцсети», карточка `account-card` в `index.html:553`,
  логика в `js/account.js` (`renderTelegram`, `hashtagSelect`, `openSchedule`).
- ВКонтакте уже подключается через VK ID (OAuth 2.1 + PKCE, `handle_vk_oauth_*` в `handlers/account.php:95`,
  `lib/sources.php:385`), но **только для чтения** и одно подключение на весь сайт. **Приложение VK на сервере не
  настроено** (`config.local.php`: `VK_CLIENT_ID => 'ВАШ_ID_ПРИЛОЖЕНИЯ'`).
- Приложение открывается на `localhost`. **Публичного HTTPS-адреса нет.** Это важно: Instagram, Threads, Facebook и
  Pinterest берут картинку **по публичной ссылке** (`image_url`), а не загрузкой файла.

## Часть A. Каркас: «ресурсы» вместо «Telegram-каналов»

1. **Миграция 16** (по образцу `lib/db.php`): пересобрать `channels` (SQLite не снимает `UNIQUE`): новая таблица с
   `platform TEXT NOT NULL`, `ref TEXT NOT NULL` (внешний id: chat_id Telegram, id группы VK, DID Bluesky, `инстанс/@ник`
   Mastodon…), `secrets_enc TEXT NOT NULL DEFAULT ''` (JSON секретов, зашифрованный целиком), `meta TEXT NOT NULL DEFAULT '{}'`
   (несекретное: имя, аватар, адрес, срок токена), `UNIQUE (user_id, platform, ref)`; остальные столбцы как были.
   Перенос: Telegram → `ref = chat_id`, `secrets_enc` = `{"token": …}` из `token_enc`. Старые столбцы Telegram оставь,
   чтобы не трогать код Telegram сверх нужного, но новый код читает `ref` / `secrets` / `meta`.
   Проверка: число каналов и их порядок до и после совпадают; публикация в Telegram на подставном HTTP проходит.
2. **Адаптеры.** Папка `lib/networks/`, по файлу на соцсеть, реестр `NETWORKS` в `lib/networks/registry.php`:
   ```php
   'vk' => ['title' => 'ВКонтакте', 'prefix' => 'vk', 'text_limit' => [16384, 16384], 'media_max' => 10,
            'kinds' => ['photo', 'video', 'animation'], 'poll' => false, 'configured' => fn() => …, 'publish' => 'vk_publish', …]
   ```
   Одна сигнатура для всех: `<сеть>_publish(array $channel, string $text, array $prepared): array` →
   `['url' => …, 'ids' => […]]` или исключение с понятным русским текстом. Плюс `<сеть>_connect(array $input): array` —
   проверить доступ и вернуть поля ресурса (`ref`, `title`, `secrets`, `meta`).
   Telegram — первый адаптер: обёртка над `telegram_publish_prepared` / `telegram_publish_poll`, без изменения поведения.
3. `outbox_send_post` и `handle_telegram_publish` (переименуй в `handle_publish`, старое имя оставь псевдонимом в
   `ROUTE_HANDLERS`, `index.php`) выбирают адаптер по `platform`. `publish_channel_resolve` работает для всех соцсетей,
   а лимит тарифа считает **все** ресурсы.
4. **Медиа под соцсеть.** `telegram_prepare_media` уже скачивает и раскладывает файлы. Если соцсеть не принимает вид
   файла или его размер (например, GIF или видео больше лимита), пропусти файл и сообщи об этом в ответе. Не падай
   целиком, пока остаётся хоть что-то. Пост без единого подходящего файла и без текста — ошибка.
5. **Интерфейс.** «Соцсети» → общий список ресурсов (Telegram как сейчас) и кнопка «+ Добавить соцсеть» со списком
   соцсетей из реестра. У каждой: подключено / подключить / «не настроено на сервере» / «недоступно» (часть D) с
   пояснением. Цели редактора — `<prefix>:<id>`, подпись `ВКонтакте «Название»`, лимиты из реестра (отдай реестр
   фронту через `channels_public` или отдельный GET). Расписание (`openSchedule`) и хэштеги (`hashtagSelect`) — у всех
   ресурсов.
6. Тест `tools/test_networks.php`: миграция (на копии базы во временном файле), выбор адаптера, пропуск неподходящих
   файлов, лимит тарифа по всем ресурсам, Telegram без изменений.

## Часть B. Соцсети, которые подключаются без проверки приложения

Порядок — по пользе для русскоязычного автора.

### B1. ВКонтакте — сообщество

- Публикация: `wall.post` с `owner_id = -<id группы>`, `from_group = 1`, `attachments`. Фото:
  `photos.getWallUploadServer(group_id)` → загрузка → `photos.saveWallPhoto(group_id)`. Видео: `video.save(group_id)` →
  загрузка. Лимит текста — 16 384, до 10 вложений.
- **Токен.** По открытым источникам `photos.getWallUploadServer` **не работает с ключом сообщества** (ошибка 27): нужен
  **ключ пользователя-администратора** с правами `wall`, `photos`, `video`, `groups`, `offline`. Сверь с dev.vk.com, какие
  права выдаёт VK ID для веб-приложения. Варианты по убыванию:
  1. отдельная кнопка «Подключить VK для публикации» через тот же VK ID с расширенным `scope`; токен — **у пользователя**
     (в его ресурсе), а не общий на сайт, как для чтения;
  2. если VK ID таких прав не даёт — ключ сообщества (`groups.getById` проверяет доступ) и публикация только текста и
     ссылок; честно написать это в интерфейсе.
- Выбор сообщества: после входа — список групп, где пользователь админ (`groups.get filter=admin extended=1`); каждая
  выбранная группа — отдельный ресурс.
- Приложение VK на сервере не настроено: инструкция владельцу в отчёте (где создать приложение VK ID, какой redirect URI,
  какие права включить).

### B2. MAX (мессенджер VK)

- Бот-API: `https://platform-api2.max.ru`, токен **только** в заголовке `Authorization`, сообщение — `POST /messages`
  (как передавать `chat_id` — по странице документации «Получение ID чата или канала»; источники расходятся: query или тело),
  файлы — `POST /uploads`, затем вложение в сообщение. По официальной странице: базовый домен `platform-api2.max.ru`, нужно
  доверять сертификату Минцифры (проверь, проходит ли TLS у нас; при необходимости — свой CA-файл для curl только для этого
  хоста, **не** отключай проверку сертификата). С июня 2026 список чатов бота — `POST /subscriptions`, а не `GET /chats`.
- Подключение — как у Telegram: токен бота + канал, куда бот добавлен админом. Токен выдаётся в «MAX для бизнеса» после
  верификации профиля: так и написать в шагах подключения.

### B3. Bluesky

- Вход: `com.atproto.server.createSession` (ник + **пароль приложения**, не основной), обновление —
  `refreshSession`. Пост: `com.atproto.repo.createRecord` с `app.bsky.feed.post`. Картинки: `uploadBlob` (до 4, размер —
  по документации, около 1 МБ: перед загрузкой сжимай). Текст — 300 графем: длиннее — обрезка с «…» и предупреждение в
  редакторе. Ссылки и хэштеги — через `facets` (байтовые смещения UTF-8!), иначе они не кликаются. Видео — по
  документации `app.bsky.video` (если сложно — пока без видео, с пометкой).

### B4. Mastodon

- Ресурс: адрес инстанса + токен доступа (пользователь создаёт его в «Настройки → Разработка», права `write:statuses`,
  `write:media`). Пост: `POST /api/v1/statuses` с `media_ids[]`, файлы — `POST /api/v2/media` (ждать обработки, пока
  `url` не появится). Лимит текста — из `GET /api/v2/instance` (`configuration.statuses.max_characters`), не жёстко 500.

### B5. Discord

- Ресурс: адрес вебхука канала (проверка — `GET` вебхука). Пост: `POST` с `payload_json` и `files[n]`. Текст — до 2000
  символов. Лимит размера файла — по документации (у серверов без бустов он недавно уменьшился).

### B6. Дзен — без API

- Публичного API публикации у Дзена нет. Зато есть официальный импорт из Telegram: в Дзен-студии → настройки канала →
  код для Telegram-бота → бот синхронизации Дзена (`@zen_sync_bot`) админом в Telegram-канал → `/sync`. После этого
  посты Telegram-канала сами выходят в Дзене: текст и картинки — статьями, только картинка или видео — короткими постами,
  заголовок — первое предложение. Сверь шаги с актуальной справкой Дзена.
- Сделать: карточка «Дзен» в «Соцсетях» с этой пошаговой инструкцией и пометкой, к какому Telegram-каналу Posta его
  привязать. Кода публикации нет.

## Часть C. Соцсети, где владелец регистрирует приложение (код готов, включается ключами)

Каждую — адаптером части A с OAuth, если не сказано иначе. **Без ключей в конфиге карточка показывает «не настроено на
сервере» и шаги для владельца.** Тесты — на подставном HTTP.

| Соцсеть | Публикация | Что нужно владельцу | Ограничения |
|---|---|---|---|
| Одноклассники (группа) | `mediatopic.post`, `type=GROUP_THEME`, `gid`; фото — `photosV2.getUploadUrl` | приложение OK; права `GROUP_CONTENT`, `PHOTO_CONTENT`, `VIDEO_CONTENT` (метод по умолчанию закрыт — запрос в api-support@ok.ru) | — |
| YouTube Shorts | `videos.insert` (резюмируемая загрузка), scope `youtube.upload` | проект Google Cloud, экран согласия OAuth | без аудита Google ролики загружаются **приватными**; только видео; вертикальное, до 3 мин |
| Pinterest | `POST /v5/pins` (`board_id`, `media_source` base64) | приложение Pinterest | на пробном доступе — ограничения видимости, см. документацию |
| Tumblr | `POST /v2/blog/{blog}/posts` (NPF-блоки) | приложение Tumblr (OAuth 2) | — |
| LinkedIn (профиль) | Posts API, `w_member_social`; картинка — `images?action=initializeUpload` | приложение с продуктом «Share on LinkedIn» | только личный профиль; страницы компаний — отдельная проверка |
| Threads | контейнер `POST /{user-id}/threads` → `/threads_publish` | приложение Meta | картинка **по публичной ссылке**, до 500 символов |
| Instagram / Facebook-страница | Graph API: контейнер → `media_publish`; страница — `/{page-id}/photos`, `/feed` | приложение Meta, профессиональный аккаунт | картинка **по публичной ссылке**; ~100 публикаций в сутки; **юридически:** Meta признана в РФ экстремистской — рядом с названиями в интерфейсе обязательна пометка «Meta (Instagram, Facebook) признана экстремистской и запрещена в РФ» |
| X (Twitter) | `POST /2/tweets`, медиа — загрузка медиа v2 | платный доступ к API | цены меняются: сверь и напиши владельцу актуальную |
| TikTok | Content Posting API: Direct Post (`/v2/post/publish/video/init/`, scope `video.publish`) и загрузка черновиком во «Входящие» (`video.upload`) | приложение TikTok for Developers + заявка на аудит | **до аудита** всё опубликованное — только `SELF_ONLY` («видно мне»), не больше 5 пользователей в сутки (официальная документация). Сделай оба режима: «опубликовать» и «отправить черновиком» (пользователь допубликует в приложении TikTok). Проверь по официальной странице `video.upload`, действует ли ограничение «только мне» и на черновики, и напиши в отчёте. В интерфейсе до аудита — честная пометка «пока TikTok не проверил приложение, посты видны только вам». Только видео (и фото-карусели — `content-posting-api-reference-photo-post`) |
| Reddit | `POST /api/submit` | приложение Reddit; для коммерческого использования — согласование | правила сабреддитов против автопостинга: только свой профиль и свои сабреддиты, с предупреждением |

**Публичная ссылка на файл** (Threads, Instagram, Facebook, Pinterest по URL): сделай отдачу файла поста по разовой
подписанной ссылке (`outbox_media` уже отдаёт файлы — посмотри, как, и добавь подпись со сроком). Пока у приложения нет
публичного HTTPS-адреса (`APP_PUBLIC_URL` в конфиге пуст), эти соцсети показывают «нужен публичный адрес сайта» и не
подключаются.
