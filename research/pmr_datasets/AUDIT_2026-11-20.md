# PMR data audit and quarantine pilot — 20 November 2026

This is an **incomplete source audit and inspection pilot**, not an approved
training release. No gated access terms were accepted and no corpus was used to
train a model. Raw data remain on the HDD, outside Git.

## Evidence and limitations

- `audit-2026-11-20.json`: HF metadata and first-row schema results for the 13
  original catalog entries. Five schema probes returned errors/unavailable;
  metadata success does not imply that source bytes are accessible.
- `audit-new-candidates-2026-11-20.json`: bounded schema probes for mMARCO
  and DataComp-HQ; the latter has no license in the retrieved card metadata.
- `root-tree-audit-2026-11-20.json` and `subtree-audit-2026-11-20.json`:
  revision-specific, bounded first pages of file listings, including the added
  Russian mMARCO candidate. They do not establish full source size.
- `/mnt/hdd_ubuntu/posta-pmr/preview-20261120/manifest.json`: four actual
  source previews, record counts and SHA-256, plus original media. Server cache
  revision is not pinned. Media hashes are checked; ten WIT preview images were
  fully decoded using Pillow. They are Dataset Server preview derivatives, not
  verified byte-identical originals; individual image-license clearance remains pending.
- `/mnt/hdd_ubuntu/posta-pmr/preview-20261120/wit-commons-rights-metadata.json`:
  Commons API metadata for all ten originals. Eight report CC BY or CC BY-SA
  licenses requiring attribution and two report public domain; these claims
  and any other restrictions need review before use.
- `/mnt/hdd_ubuntu/posta-pmr/Posta-Dataset-v0.1-review-verified/manifest.json`:
  normalized task/split files, source manifest hash, counts, rejection and
  duplicate reports. Its media paths refer to the preview directory.

The review build contains 66 records: 17 Russian and 20 English web documents,
20 KaLM query/document examples, and nine WIT image-caption examples (language
`und`). One WIT caption failed minimum text length; zero exact duplicates were
removed. Split totals are 57 train, 6 validation and 3 test. These names only
exercise partitioning and do not certify an independent evaluation. The 20
KaLM examples have language `und`: no independent language classification was
performed. Ten images decoded; one does not appear in normalized examples due
to the rejected caption.

## Before a training release

Review upstream dataset and individual media terms, attribution, privacy and
PII; choose permitted source subsets; obtain revision-pinned shards or another
verifiably pinned export; check schema and sample quality across source families;
exclude independent benchmark data including indirect/translated overlap; add
near-duplicate and source-family checks; establish language/topic balance; and
collect validated OCR, video and audio bytes. Current sample is neither
representative nor large enough for training. Exact component splitting alone
cannot guarantee absence of near-duplicate or benchmark leakage.
